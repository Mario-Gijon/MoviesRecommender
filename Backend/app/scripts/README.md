# Scripts

This folder will hold local helper scripts for catalog preparation and maintenance.

Current scripts cover placeholder catalog seeding plus MovieLens 32M download, inspection, candidate-generation, offline TMDB enrichment, and enriched-catalog inspection helpers.

The previous `ml-latest-small` pipeline has been removed. MovieLens 32M is now the active offline dataset source, and final demo-catalog generation will be added on top of the 32M enrichment path next.
