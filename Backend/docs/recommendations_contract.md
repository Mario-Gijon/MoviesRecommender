# Recommendation API contract

## Canonical API

```http
POST /recommendations
Content-Type: application/json
```

Request:

```json
{
  "requestId": "unity-request-42",
  "strategy": "collaborative",
  "algorithm": "item_knn",
  "ratings": [
    {"movieId": 1, "rating": 5},
    {"movieId": 260, "rating": 4},
    {"movieId": 296, "rating": 2}
  ],
  "limit": 10
}
```

`requestId` is optional. A provided value must be a string containing at least
one non-whitespace character and no more than 128 characters. Valid values are
preserved exactly. A missing value is generated by the backend. An invalid
value rejects the request, and the error response uses a generated identifier.
Generated identifiers are non-persistent UUID-based values prefixed with
`rec-`.

Successful response:

```json
{
  "requestId": "unity-request-42",
  "strategy": "collaborative",
  "algorithm": "item_knn",
  "recommendations": [
    {
      "rank": 1,
      "movie": {
        "movieId": 3114,
        "id": 3114,
        "title": "Toy Story 2",
        "year": 1999,
        "genres": ["Adventure", "Animation", "Comedy"],
        "tags": ["toy", "friendship", "pixar"]
      },
      "score": 0.74,
      "matchPercentage": 68.5,
      "explanation": {
        "summary": "Users with similar preferences rated this movie positively.",
        "reasons": [
          "The movie has a strong score among similar users."
        ]
      }
    }
  ],
  "meta": {
    "limit": 10,
    "count": 1
  }
}
```

The `movie` object uses the existing `PublicMovieRecord` catalogue schema.

Error response:

```json
{
  "requestId": "unity-request-42",
  "error": {
    "code": "insufficient_ratings",
    "message": "There are not enough ratings to run this recommender.",
    "details": {
      "minimumRequired": 3,
      "received": 2
    }
  }
}
```

Canonical request-validation errors use the same shape with HTTP `422`.

Registered combinations:

| Strategy | Algorithm | Empty ratings |
| --- | --- | --- |
| `content` | `tfidf` | Rejected; requires three non-neutral ratings |
| `collaborative` | `popularity` | Accepted |
| `collaborative` | `item_knn` | Rejected; requires a rating |
| `collaborative` | `user_knn` | Rejected; requires a rating |
| `collaborative` | `biased` | Rejected; requires a rating |

## Deprecated compatibility APIs

```http
POST /recommendations/content-based
POST /recommendations/collaborative
```

These routes remain marked as deprecated and temporarily retain their previous
request and response contracts.

The content-based route continues to accept `int | float` ratings, `limit`, and
`templateSessionId`, and returns the previous content profile, score,
explanation, recommender-detail, algorithm-detail, template, and limit fields.

The collaborative route continues to accept its previous ratings, `limit`, and
`templateSessionId`, selects the configured collaborative algorithm, and
returns the previous collaborative profile, score, explanation,
algorithm-detail, recommender-detail, template, and limit fields.
