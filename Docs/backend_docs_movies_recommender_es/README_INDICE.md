# Documentación Backend Movies Recommender

## Documentos incluidos

1. `README_01_RESUMEN_RAPIDO.md`
   - Resumen rápido del backend y estado actual.

2. `README_02_PIPELINE_Y_SCRIPTS.md`
   - Explicación de cada script, qué lee y qué genera.

3. `README_03_DICCIONARIO_CAMPOS_PELICULA.md`
   - Diccionario de campos de cada película.

4. `README_04_ARCHIVOS_GENERADOS.md`
   - Explicación de CSVs y JSONs generados.

5. `README_05_MAPA_BACKEND.md`
   - Mapa de ficheros backend y responsabilidades.

6. `README_06_GUIA_LLAMADA.md`
   - Guía corta para explicar el proyecto en una llamada.
